# Vitrina

Counter for a local shop. Price an offer, keep the cost and margin private, and leave with a WhatsApp message plus a square card for Instagram, Threads, and LinkedIn.

The working app is in the Cursor project that created this repository. Run it with `npm install` and `npm run dev`, then open http://127.0.0.1:3847.

Examples are fictional shops. Tax presets are general 2026 rates, not tax advice.
